How to Use Smokin' Hot Info Techs

1

Setup Teams

Go to Manager Setup to add teams and set the nomination order.

2

Start Admin

Open the Admin Panel and click "Start Draft" to begin the auction.

3

Run the Draft

Use the Admin Panel to nominate players, manage bids, and advance turns.

4

Monitor Live

Display the TV Display and view rosters in League Viewer.

Requirements

Before you begin, make sure you have:

  • ✓ Teams added in Manager Setup
  • ✓ Nomination order set (unique positive numbers)
  • ✓ Admin authenticated (sign in required)
  • ✓ A screen for the TV display (optional but recommended)
